# AJ20 Comparator Priority Scheduler

Create a scheduler that can order tasks using different comparator strategies.

## Requirements
- Model tasks with name, deadline, importance, and estimated duration.
- Support at least three ordering policies.
- Compare a sorted-list implementation with a `PriorityQueue` implementation.
- Explain which collection is better for repeated insertion and next-task retrieval.
- Include custom cases where two tasks tie on the primary field.

## Stretch
- Allow users to switch ordering policy while tasks are already loaded.
