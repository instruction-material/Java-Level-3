# Collections checkpoint workbook

Build small, testable operations that reuse nested types, generics, a singly and doubly linked list, a stack, two kinds of queues, and maps. The given records and node fields provide the representations. Complete the marked operations. Use the failure policy in the course worksheet. Run the default contract suite before attempting the optional grouped-count mode.

This reference passes the supplied contract checks.

```sh
javac --release 21 -Xlint:all -Werror Main.java ContractTests.java
java ContractTests
java Main
```

For optional grouping, run `java ContractTests groups` and `java Main groups`.
