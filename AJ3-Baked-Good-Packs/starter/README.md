# Price a bread subclass

Represent shared baked-good data with an abstract class. Implement Bread.priceCents using the size enum. Small, medium and large loaves cost 250, 350 and 450 cents. Sort by ingredient count.

The starter compiles and identifies the first unfinished method when checks run.

```sh
javac --release 21 -Xlint:all -Werror Main.java ContractTests.java
java ContractTests
java Main
```
