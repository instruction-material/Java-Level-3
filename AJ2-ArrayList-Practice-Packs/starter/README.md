# Build a filtered ArrayList

Build a different ArrayList containing the even values in encounter order. Keep zero, negative evens, and duplicate evens. Keep the input list unchanged when filtering and searching. Find a zero-sum pair of distinct positions. Provide two mutating methods that remove the first minimum and append the checked sum.

The starter compiles and identifies the first unfinished method when checks run.

```sh
javac --release 21 -Xlint:all -Werror Main.java ContractTests.java
java ContractTests
java Main
```
