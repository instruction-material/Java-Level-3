# AJ22 Event-Driven Simulation Capstone

Build a medium-size Java simulation that proves readiness for larger software work.

## Project Options
- Tournament scheduler
- Delivery dispatch board
- Library queue simulator
- Course registration system

## Requirements
- Use packages to separate model, service, parsing, and runner code.
- Define at least two interfaces.
- Load initial state from a file or command script.
- Process events through a clear event loop or task queue.
- Include a test harness or documented manual verification cases.
- Explain one architecture tradeoff in the final notes.

## Stretch
- Add save/load support and a replayable event log.
