# AJ19 Characterization Test Bug Fix

Start with a small buggy service, write tests that describe current behavior, and then make a focused safe fix.

## Requirements
- Choose or create a service with at least one real bug in calculation, parsing, or validation.
- Write characterization tests before changing implementation code.
- Identify which current behaviors are intentional and which are defects.
- Fix one defect in the smallest safe step.
- Update or add tests to describe the intended behavior after the fix.

## Stretch
- Add one refactor after the behavior is protected by tests.
