# Sources and exercise scope

This original exercise addresses the existing clinic's specific refactoring purpose. Its limits, error messages, outputs and application policies are course-specific contracts.

- [Java integer division](https://docs.oracle.com/javase/specs/jls/se21/html/jls-15.html#jls-15.17.2).
- [Java 21 List](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/List.html).

The project uses the Java standard library and needs no package installation. Retain exact before/reference behavior, independent optional attempts and source checkpoints. A reference design and passing checks support a review; a learner supplies the design judgment and actual work record.
