# AJ19 Tested Gradebook Service

Build a package-organized gradebook service with a thin console runner and independently testable domain logic.

## Requirements
- Model students, assignments, and scores with clear classes.
- Validate score ranges and missing assignment cases before mutating state.
- Support weighted averages and a final letter-grade report.
- Keep console input separate from the gradebook service.
- Include a small test harness with at least five custom cases.

## Stretch
- Add category weights such as quizzes, homework, and exams.
- Add a dropped-lowest-score option and explain how it changes the average.
