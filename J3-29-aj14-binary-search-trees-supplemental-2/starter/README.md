# BST traversal transfer practice

List all keys from a binary search tree in the inclusive range. Return keys in ascending order without mutating the tree. Use the ordering invariant to skip subtrees outside the requested interval. A reversed interval has no results.

The starter compiles and identifies the first unfinished method when checks run.

```sh
javac --release 21 -Xlint:all -Werror Main.java ContractTests.java
java ContractTests
java Main
```
