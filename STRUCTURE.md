# Java-Level-3 Structure

This repository is the canonical Java advanced/design-patterns/refactoring
monorepo. It intentionally backs multiple public courses.

Prefix ownership:

- `J3-*`: Java Level 3
- `DPJ-*`: Design Patterns in Java
- `DPR-*`: Design Patterns in Java Part 2: Refactoring
- `AJ*`: legacy Advanced Java direct-source projects

Active public folders stay at the repository top level and must be linked by the
live catalog. Folders not linked by the live catalog on 2026-05-14 were moved to
`_archived-unlinked/`.

Do not add a new top-level folder without using the appropriate prefix and
updating the live catalog or backlog note in the same change.
