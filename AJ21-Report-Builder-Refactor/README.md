# AJ21 Report Builder Refactor

Refactor a messy report generator into clear stages.

## Requirements
- Start with or create a report generator that mixes parsing, aggregation, formatting, and output.
- Split the workflow into named stages.
- Keep each stage independently testable with simple inputs.
- Preserve the original externally visible output unless an intentional change is documented.
- Explain which stage would be easiest to replace after the refactor.

## Stretch
- Add a second output format such as plain text and CSV.
