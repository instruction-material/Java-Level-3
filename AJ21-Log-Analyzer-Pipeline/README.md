# AJ21 Log Analyzer Pipeline

Build a file-backed log analyzer with clear pipeline stages.

## Requirements
- Read log rows from a text file.
- Parse valid rows into records and collect invalid rows separately.
- Group events by type or user.
- Compute summary statistics such as counts, first/last event, and most frequent category.
- Implement one version with loops and refactor one stage to streams.

## Stretch
- Add a report sorted by frequency and then by name.
